# 🚨 SafeCity — AI-Powered Women Safety Platform

SafeCity is a full-stack, AI-powered safety application designed to help users respond quickly during emergencies and make safer decisions in real-time.

Built with the goal of solving real-world safety challenges, SafeCity combines **emergency response**, **real-time tracking**, and **AI-driven insights** into a single platform.

## ⚡ Key Features

### 🚨 One-Tap SOS
Instantly sends your **live GPS location via SMS** to trusted contacts during emergencies.

### 📍 Live Location Sharing
Continuously updates location during critical situations for faster response.

### 🚓 Nearest Police Station Finder
Quickly identifies the closest police station based on your current location.

### 🔥 Crime Heatmap
Visualizes high-risk areas using location-based crime data.

### 🤖 AI Safety Score
Evaluates how safe a location is based on nearby crime patterns.

### ⏳ AI Danger Prediction
Predicts risk levels based on **time and day patterns**.

### 📊 NGO Admin Dashboard
- Real-time SOS alerts  
- Data visualization (charts & reports)  
- Incident management system  

---

## 🧠 Problem It Solves

Many existing safety solutions rely only on manual SOS triggers, which fail in critical scenarios where the user cannot react.

SafeCity focuses on:
- **Fast emergency response**
- **Better situational awareness**
- **Data-driven safety insights**
